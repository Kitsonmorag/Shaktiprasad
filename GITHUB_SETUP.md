# Upload this portfolio to GitHub

This project now contains your profile README at the repository root and the deployable portfolio website in `site/`.

1. Create a public repository named exactly the same as your GitHub username. GitHub will display this repository’s `README.md` on your profile.
2. In the repository’s **Add file → Upload files** page, drag in the contents of this project folder, keeping the same folder structure, then commit the upload.
3. Open **Settings → Pages** and set the build source to **GitHub Actions**. The included workflow deploys the contents of `site/` after you push to `main`.
4. The profile README will appear on your GitHub profile. The website URL will be `https://YOUR-USERNAME.github.io/YOUR-USERNAME/` once Pages finishes deploying.

The README currently links to the portfolio URL listed on your CV. After GitHub Pages is live, you can replace that link with the new Pages URL.
